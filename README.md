## 🚀 About Me

I am an **AI Tech Lead** passionate about designing and building intelligent, scalable and enterprise-ready AI solutions.

My focus is on **Generative AI, Agentic AI, Retrieval-Augmented Generation (RAG), and intelligent automation**, combining enterprise software engineering with emerging AI technologies.

I enjoy exploring how AI agents can reason, retrieve knowledge, collaborate, use tools and execute complex business workflows.

- 🤖 Designing and developing enterprise Agentic AI applications.
- 🧠 Exploring multi-agent architectures and autonomous AI workflows.
- 🔍 Building advanced RAG solutions with hybrid search and reranking.
- ☕ Developing AI-powered applications using Java, Spring AI and LangChain4j.
- 🐍 Exploring Python for AI engineering and agent development.
- 🧩 Working with Anthropic Claude, Claude API and Claude Agent SDK.
- 🔌 Exploring MCP, AI tool integration and agent orchestration.
- ✍️ Practicing prompt engineering and context engineering.
- 🛡️ Interested in Responsible AI, governance and enterprise AI adoption.
